# Quick Notes

Quick Notes is a lightweight browser-based note-taking app for capturing short notes, organizing them by category, and finding them quickly. Notes are saved in the browser's local storage, so they remain available on the same browser between visits.

## Features

- Add notes with Personal, Work, or Ideas categories.
- Search notes as you type.
- Delete notes you no longer need.
- Validate that notes contain text and are no longer than 200 characters.
- Save and restore notes using browser local storage.
- Show the current note count and adapt the layout for small screens.
